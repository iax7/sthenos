# Rules (non-negotiable)

- **All generated text must be in English.** This applies to code, comments,
  commit messages, GitHub issues, PR bodies, and issue/PR comments.
- Do not write Spanish (or any other language) in the repo or on GitHub unless
  the user explicitly requests otherwise.
- These rules override the language of the surrounding conversation. A user
  replying in Spanish triggers this rule, not an exemption.
